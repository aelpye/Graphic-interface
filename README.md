
Задания по теме Графический интерфейс пользователя

В данном репозитории собраны три программы на языке Python. Для заданий 2 и 3 (где требуются сложные интерфейсы и графики) использована библиотека PyQt6. Для простого калькулятора (Задание 1) использован встроенный модуль Tkinter.
Пошаговая инструкция по установке и запуску

Чтобы запустить программы, выполните следующие шаги в терминале:

Шаг 1. Создание виртуального окружения

Виртуальное окружение нужно для того, чтобы установленные библиотеки не конфликтовали с системными. Откройте терминал в корневой папке проекта и выполните команду:

python3 -m venv venv

Шаг 2. Активация виртуального окружения

В зависимости от вашей операционной системы, выполните нужную команду.

Для Linux и macOS:

source venv/bin/activate

Для Windows (командная строка):

venv\Scripts\activate

Для Windows (PowerShell):

.\venv\Scripts\Activate.ps1

После активации в начале строки терминала появится значок (venv)

Шаг 3. Установка зависимостей

Установите библиотеки, необходимые для работы второго и третьего заданий:

pip install PyQt6 matplotlib

Для калькулятора на Tkinter ничего устанавливать не нужно, он встроен в Python.
Запуск программ
Задание 1. Калькулятор (Tkinter)

Простой калькулятор с валидацией ввода (защита от букв), обработкой исключений и поддержкой ввода с клавиатуры. Запуск:

python3 main1.py

Задание 2. Формы учёта-отчёта (PyQt6)

Приложение для ведения базы пациентов. Включает строгую валидацию данных (только кириллица, ограничения по возрасту/росту/весу, выбор пола), расчёт ИМТ, сохранение в JSON и построение 4 графиков. Запуск:

python3 main22.py

Примечание: данные автоматически сохраняются в файл patients.json.
Задание 3. Урезанный FastQC (PyQt6)

Графический интерфейс для анализа файлов формата FASTQ. Поддерживает выбор файла через диалог (с фильтром форматов) и функцию Drag-and-Drop (перетаскивание файлов в окно). Запуск:

python3 fastq1.py

Примечание: для тестирования в папке лежит файл test.fastq. Логика парсинга FASTQ вынесена в отдельный модуль fastq_parser.py.

Структура заданий

main1.py — Калькулятор (Tkinter)
main22.py — Формы пациентов (PyQt6)
fastq1.py — Интерфейс FastQC (PyQt6)
fastq_parser.py — Модуль логики для FastQC
test.fastq — Тестовый файл для проверки FastQC
patients.json — База данных пациентов
